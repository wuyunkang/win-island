# 灵动岛

Windows 原生 Rust 灵动岛。以 [Daozai](https://github.com/Renly1994/xiaotang-daozai) 的 [inlayin/win-tool 分支](https://github.com/inlayin/win-tool)为基础，首轮增加微信／钉钉提醒与通用实时活动。

这是基于上游源码继续开发的独立 Rust 项目。保留音乐、歌词、邮箱、日历、待办和专注，移除吉祥物、饮水、原作者赞助及宣传入口。剪贴板和外观配置参考本机 BrimDeck 的行为重新实现；真实账号接入仍需各自配置和验收。

## 界面与剪贴板

- 展开区域统一为 520×240。左侧提供音乐、专注、剪贴板、待办、邮箱、AI 额度、日程七个图标入口，悬停显示名称；选中后显示功能配色，间距 28 点。
- 右侧内容适配放大的卡片：音乐的封面、歌词、进度与控制重新布局；专注扩大计时区域；待办一屏七项；邮件扩大列表和正文；日程增加可见事项，AI 额度扩展账号和状态区域。
- 剪贴板移除搜索行，记录单行显示，来源、时间和完整路径移到悬停提示；支持文本、链接、代码、颜色、图片，以及从资源管理器复制的单个或成组文件／文件夹。
- 文件记录保留 Windows 文件格式，点击可重新粘贴，右键支持只复制、纯文本路径、详情、常用和分类；文件已移动或删除时提示失败，不静默漏掉文件。
- 已移除独立文件中转站、文件专用设置和自动拖入捕获区。清除剪贴板记录不会删除原文件。
- 常用、保留分类在退出后保留，普通记录退出清理；支持来源进程排除、密码管理器的禁止记录标记和当前 Windows 用户的 DPAPI 加密存储。文件内容不复制进数据目录。
- 分类支持名称、颜色、顺序、任一／全部条件与正则规则；外观设置提供停靠、屏幕、统一缩放、主题、字体、透明度、展开方式、动画和帧率。

## 图形与交互

Windows 默认使用 Direct3D 12 并优先高性能设备，通过 DirectComposition 合成逐像素透明圆角；保留羽化边缘，不再用整数轮廓硬裁剪。图形初始化失败时回退 OpenGL。排障可用 ISLAND_RENDERER=glow 或 ISLAND_RENDERER=wgpu 指定后端。

点击微信提醒会在后台恢复对应账号窗口并尝试托盘唤回。绘制画布为 960×360，帧等待扣除本帧耗时，界面线程不额外睡眠。

## 首轮新增

- 本机 HTTP 接口提交短通知或持续任务，支持进度、同 ID 更新、优先级、自动过期、撤销与状态查询。
- 实时任务在岛上显示；微信、钉钉等消息提醒临时打断任务，提醒结束后恢复活动。「关闭」只移除展示，不终止外部程序。
- 钉钉任务栏请求关注监听、重复合并、未读入口和窗口切换；与 Windows 通知中的钉钉预览合并。
- 微信保留上游的任务栏事件、多开区分，并在点击提醒时自动尝试托盘唤回。
- 数据目录、凭据服务名、单实例与开机启动标识独立；关闭上游自更新入口，避免更新回原版 Daozai。

原生界面使用 egui/eframe，Windows 能力通过 `windows` crate 调用。`crates/island-events` 是独立的活动状态与 HTTP 模块，不依赖 GUI 或 Win32。

## 运行与构建

免安装包解压后直接运行 `灵动岛.exe`，源码目录可双击 `启动.cmd`；下面的命令用于源码开发。

Windows 10/11 x64。当前机器已配置用户目录下的 Rust 与 LLVM/MinGW。其他电脑先运行 `./scripts/bootstrap.ps1`，不修改系统 PATH。

```powershell
# 开发运行
./scripts/dev.ps1 -Action Run
# 运行并临时启用实时活动接口
./scripts/dev.ps1 -Action Run -ActivityApi
# 测试（单线程，隔离上游测试使用的进程环境变量）
./scripts/dev.ps1 -Action Test
# 生成免安装包
./scripts/package-portable.ps1
```

已有 MSVC 构建工具和 Windows SDK 也支持 `cargo build --locked --bin win-island-rust`。开发脚本优先使用用户目录的 LLVM/MinGW。

## 通知与实时活动

打开「设置 → 通知」，按需启用微信、钉钉任务栏提醒；读取正文需连接 Windows 通知并由用户授权。正文默认隐藏。

启用「本机实时活动」后默认监听 `127.0.0.1:17831`。运行 `./scripts/activity-demo.ps1` 演示构建进度与完成提醒。脚本从数据目录的 `live-api.json` 读取当前地址和临时令牌，完整说明见 [接口文档](docs/ACTIVITY_API.md)。

## 数据与限制

- 默认目录 `%APPDATA%\WinIslandRust`，用 `WIN_ISLAND_DATA_DIR` 指定开发或测试目录。保留 `DAOZAI_DATA_DIR` 作为上游测试兼容入口，新变量优先。
- 接口默认关闭，只监听本机，需要 Bearer 令牌，不接收浏览器 Origin 请求。
- 微信／钉钉任务栏提醒只表示请求关注，不包含聊天正文、准确消息数量或聊天已读状态；正文只能来自客户端提供的系统通知。
- 实际通知、Windows 权限与窗口行为受客户端版本影响，需要真实消息验收。
- 自动粘贴受 Windows 前台激活权限和目标程序权限影响；无法激活时会保留已复制的内容并提示手动 Ctrl+V。
- 剪贴板文件历史保存路径引用，原文件移动、重命名或删除后，需要重新复制。加密存储保护历史路径和元数据，不加密原文件。
- Agent 审批、OCR、NAS 上传、插件市场等候选功能尚未纳入本轮实现。
