# 灵动岛

Windows 原生 Rust 灵动岛。以 [Daozai](https://github.com/Renly1994/xiaotang-daozai) 的 [inlayin/win-tool 分支](https://github.com/inlayin/win-tool)为基础，首轮增加微信／钉钉提醒与通用实时活动。

这是基于上游源码继续开发的独立 Rust 项目。保留音乐、歌词、邮箱、日历、待办和专注，移除吉祥物、饮水、原作者赞助及宣传入口。剪贴板和外观配置参考本机 BrimDeck 的行为重新实现；真实账号接入仍需各自配置和验收。

## 界面与剪贴板

- 展开区域统一为 520×240。左侧提供音乐、专注、剪贴板、待办、邮箱、AI 额度、日程、天气和系统监控九个图标入口，悬停显示名称；选中后显示功能配色。
- 「设置 → 页面管理」可分别控制每个功能的胶囊态和展开态，并拖动调整顺序；胶囊预览随当前开关和数据状态变化。各功能设置页顶部提供只读展开页预览。关闭显示不会删除数据或关闭提醒；没有音乐视图时会暂停媒体轮询。
- 剪贴板、待办、邮箱和日程的胶囊组件默认关闭，可按需启用；数字分别表示记录数、今日未完成事项、当前已加载且状态已知的未读邮件及今日日程。未取得邮件已读状态时不推算数量。
- 右侧内容适配放大的卡片：音乐的封面、歌词、进度与控制重新布局；专注扩大计时区域；待办一屏七项；邮件扩大列表和正文；日程增加可见事项，AI 额度扩展账号和状态区域。
- 剪贴板移除搜索行，记录单行显示，来源、时间和完整路径移到悬停提示；支持文本、链接、代码、颜色、图片，以及从资源管理器复制的单个或成组文件／文件夹。文字、Office 文档、文件夹和压缩包使用不同图标，收藏标记单独显示。
- 文件记录保留 Windows 文件格式，点击可重新粘贴，右键支持只复制、纯文本路径、详情、常用和分类；文件已移动或删除时提示失败，不静默漏掉文件。
- 已移除独立文件中转站、文件专用设置和自动拖入捕获区。清除剪贴板记录不会删除原文件。
- 常用、保留分类在退出后保留，普通记录退出清理；支持来源进程排除、密码管理器的禁止记录标记和当前 Windows 用户的 DPAPI 加密存储。文件内容不复制进数据目录。
- 分类支持名称、颜色、顺序、任一／全部条件与正则规则；外观设置提供停靠、屏幕、统一缩放、主题、字体、透明度、展开方式、动画和帧率。

## 系统监控与个性化设置

- 系统监控显示 CPU、内存、GPU、实时上传/下载、固定磁盘空间和高占用应用；进程可按 CPU 或内存排序，趋势保留最近 60 个样本。
- 支持 1、2、5 秒后台采样，仅在监控页、监控设置预览或监控胶囊可见时读取。GPU 为 Windows 性能计数器中最忙引擎的占用，多个显卡取最高值；未取得的读数显示「—」。
- 页面管理可独立开启监控胶囊，横向显示 CPU/内存，侧边停靠显示 CPU 并在悬停时补充内存。旧版本的排列和全部关闭的选择保留，升级不会自动打开监控胶囊。
- 设置侧栏按「基础设置、桌面组件、效率工具、消息与日程、应用」分组，设置窗口支持深浅色与跟随系统。
- 主题卡片展示缩略图、背景/文字/强调色色点与选中标签。提供深浅色、One Dark Pro、GitHub 深浅色、Dracula、Night Owl、赛博霓虹、海岛假日和 Nord，支持自定义颜色与十六进制输入。
- 各功能设置提供只读预览和显示状态标签；外观页增加停靠位置示意，通知页提供带「示例数据」标记的正文隐私预览。
- 隐藏页面按需释放图片纹理、目录查询和监控线程；开启导航入口不会单独启动音乐、天气或 AI 查询。需要显示的胶囊和预览仍可读取数据，收信、剪贴板记录与日程提醒按各自开关继续工作。
- Direct3D 12 使用节省内存的分配模式，保持原有绘制后端、显卡选择和画质；关闭设置窗口后清理其图片加载缓存。

## AI 会话与额度

- 原“AI 额度”入口改为“AI”，展开页通过“会话 / 额度”切换，现有账户、配色、排序与显示开关保留。
- 首版只读接入 Codex 桌面版和 CLI 本机会话，自动跟随最近有实际活动的主会话，也可从列表固定。展开时保持当前会话，其他会话活跃时提供切换提示。
- 「设置 → AI」及「设置 → 页面管理 → 状态组件」提供独立的「Agent 状态胶囊」开关，与 AI 额度胶囊分别控制，也可同时显示；Codex / DSH 的来源开关独立保留。常驻排列可分别拖动 Agent 和 AI 额度。
- Codex 与 DSH 各自保留标志：空闲时分别显示灰白图标；思考时为呼吸环与环绕光点，运行 / 回答时为旋转弧线，完成显示绿色勾选，中断 / 异常 / 待确认使用独立标记。完成或中断分别保留 6 秒后回到灰白图标，动画只在可见时绘制。
- 同时运行时横向并排显示，各自只保留项目名；侧边停靠只显示图标与状态动画。每个来源显示最近的活跃会话，点击图标打开对应会话；来源、文字状态、完整项目名、任务和错误详情可悬停查看。
- Codex 优先使用桌面端设置的项目名，改名后自动刷新；没有可用名称时显示工作目录名。会话列表和展开页使用同一名称，兼容项目子目录、多根目录和已归属项目的独立工作树。展开页滚动查看最近一轮公开请求、进展和答复，支持复制答复和返回已有 Codex 桌面窗口。
- 自动使用 `CODEX_HOME` 或用户的 `.codex` 目录，可在设置中指定。无需为会话读取登录额度账户；不显示内部推理、系统提示或工具原始输入输出，不另存会话正文。
- 初次发现最多读取最近 32 份日志的尾部；显示期间恢复的旧会话会通过目录通知进入候选，固定会话持续保留。超长历史不整份回放，截断内容会显示提示。
- 胶囊仅读取摘要，正文最多保留 64 条、256 KiB。隐藏或最小化后释放读取线程、目录监听、文件句柄和正文缓存；重新显示后增量补读。设置提供运行、完成、空闲、异常、待确认、同时运行和思考的只读示例预览。
- 使用 `--ai-settings` 启动可直接查看 AI 设置与预览，不改变已有页面和胶囊开关。
- DSH 通过独立的只读插件接入同一会话列表，支持 DeepSeek Harness Desktop 0.2.2-rc.3。可显示等待确认、公开回复、工具摘要与可读取的计划 / 上下文指标；额度账户与会话来源互不绑定。
- 便携版附带 `dsh-bridge` 安装目录；在该目录运行 `install.ps1` 安装到桌面 profile。桥接复用 DSH 运行环境，隐藏后解除自己的订阅并释放正文缓存，详见 [桥接说明](plugins/dsh-island-bridge/README.md)。

## 图形与交互

Windows 默认使用 Direct3D 12 并优先高性能设备，通过 DirectComposition 合成逐像素透明圆角；保留羽化边缘，不再用整数轮廓硬裁剪。图形初始化失败时回退 OpenGL。排障可用 ISLAND_RENDERER=glow 或 ISLAND_RENDERER=wgpu 指定后端。

点击微信提醒会在后台恢复对应账号窗口并尝试托盘唤回。绘制画布为 960×360，帧等待扣除本帧耗时，界面线程不额外睡眠。

## 首轮新增

- 本机 HTTP 接口提交短通知或持续任务，支持进度、同 ID 更新、优先级、自动过期、撤销与状态查询。
- 实时任务在岛上显示；微信、钉钉等消息提醒临时打断任务，提醒结束后恢复活动。「关闭」只移除展示，不终止外部程序。
- 钉钉任务栏请求关注监听、重复合并、未读入口和窗口切换；与 Windows 通知中的钉钉预览合并。
- 微信保留上游的任务栏事件、多开区分，并在点击提醒时自动尝试托盘唤回。
- 数据目录、凭据服务名、单实例与开机启动标识独立；关闭上游自更新入口，避免更新回原版 Daozai。

原生界面使用 egui/eframe，Windows 能力通过 `windows` crate 调用。`crates/island-events` 是独立的活动状态与 HTTP 模块，不依赖 GUI 或 Win32。

## 运行与构建

免安装包解压后直接运行 `灵动岛.exe`，源码目录可双击 `启动.cmd`；下面的命令用于源码开发。

Windows 10/11 x64。当前机器已配置用户目录下的 Rust 与 LLVM/MinGW。其他电脑先运行 `./scripts/bootstrap.ps1`，不修改系统 PATH。

```powershell
# 开发运行
./scripts/dev.ps1 -Action Run
# 运行并临时启用实时活动接口
./scripts/dev.ps1 -Action Run -ActivityApi
# 测试（单线程，隔离上游测试使用的进程环境变量）
./scripts/dev.ps1 -Action Test
# 生成免安装包
./scripts/package-portable.ps1
```

已有 MSVC 构建工具和 Windows SDK 也支持 `cargo build --locked --bin win-island-rust`。开发脚本优先使用用户目录的 LLVM/MinGW。

## 通知与实时活动

打开「设置 → 通知」，按需启用微信、钉钉任务栏提醒；读取正文需连接 Windows 通知并由用户授权。正文默认隐藏。

启用「本机实时活动」后默认监听 `127.0.0.1:17831`。运行 `./scripts/activity-demo.ps1` 演示构建进度与完成提醒。脚本从数据目录的 `live-api.json` 读取当前地址和临时令牌，完整说明见 [接口文档](docs/ACTIVITY_API.md)。

## 数据与限制

- 默认目录 `%APPDATA%\WinIslandRust`，用 `WIN_ISLAND_DATA_DIR` 指定开发或测试目录。保留 `DAOZAI_DATA_DIR` 作为上游测试兼容入口，新变量优先。
- 接口默认关闭，只监听本机，需要 Bearer 令牌，不接收浏览器 Origin 请求。
- 微信／钉钉任务栏提醒只表示请求关注，不包含聊天正文、准确消息数量或聊天已读状态；正文只能来自客户端提供的系统通知。
- 实际通知、Windows 权限与窗口行为受客户端版本影响，需要真实消息验收。
- 自动粘贴受 Windows 前台激活权限和目标程序权限影响；无法激活时会保留已复制的内容并提示手动 Ctrl+V。
- 剪贴板文件历史保存路径引用，原文件移动、重命名或删除后，需要重新复制。加密存储保护历史路径和元数据，不加密原文件。
- Agent 审批、OCR、NAS 上传、插件市场等候选功能尚未纳入本轮实现。
